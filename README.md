# sql-practice

Учебная база для SQL-трека «junior-аналитик данных». Домен: интернет-магазин
электроники и товаров для дома — на ней же пойдут агрегаты, JOIN-ы, окна,
воронки и retention в следующих неделях.

## Как развернуть (один раз, ~5 минут)

1. Открыть DBeaver, подключиться к серверу: `localhost:5432`, пользователь
   `postgres`, пароль — тот, что задавали при установке PostgreSQL.
2. В SQL Editor выполнить `00_create_db.sql` — создастся база `sql_practice`.
   Если база уже есть, PostgreSQL скажет `already exists` — это не ошибка.
3. Переключиться на базу `sql_practice` (в DBeaver — выбрать её в дереве слева)
   и выполнить по очереди `01_schema.sql` и `02_seed.sql`.

После этого в базе 5 таблиц: `customers` (10 строк), `products` (8),
`orders` (20), `order_items` (25), `events` (40).

## Схема

```
customers 1---* orders 1---* order_items *---1 products
     |                      (quantity, unit_price)
     +---* events (view / add_to_cart / purchase)
```

- `customers.city` может быть NULL — это специально, для задач на `IS NULL`.
- `orders.status`: `paid`, `pending`, `cancelled`.
- `orders.total_amount` согласован с `order_items`: сумма = Σ(quantity × unit_price).

## Файлы

| Файл | Что это |
|---|---|
| `00_create_db.sql` | создать базу `sql_practice` |
| `01_schema.sql` | таблицы, ключи, ограничения |
| `02_seed.sql` | данные (согласованные суммы) |
| `week1_tasks.sql` | 20 задач недели 1: SELECT, WHERE, ORDER BY, LIMIT, DISTINCT |

Готовых ответов в репозитории нет и не будет: задачи решаются самостоятельно,
запросы пишутся в `week1/my_queries.sql`.

## Правила работы

- **Запрос пишешь сам.** Разбор — по твоему запросу: что не так и куда смотреть,
  без готового решения.
- **1 неделя = 1 артефакт в репозитории.** Свои решения складывай в `week1/my_queries.sql`
  (следующие недели — `week2/`, `week3/`).
- Коммит после каждой недели: `git commit -m "week1: 20 запросов"`.
- Ошибки — в `errors.md`: «что перепутал → как правильно». Это ценнее конспектов.

## Что дальше

- Неделя 2: `GROUP BY`, `HAVING`, агрегаты, `JOIN`, `UNION` — на этих же таблицах
  (выручка по категориям, топ клиентов, заказы без товаров).
- Неделя 3: подзапросы (`IN`, `EXISTS`), CTE (`WITH`), оконные функции.
- Неделя 4: воронка `view → add_to_cart → purchase`, retention по когортам,
  месячная выручка — те самые 10 аналитических запросов.
